## 保留约定

- NH 原标志与独立黑红favicon，直角、纸墨朱红。页头不重复顶部标签；首屏要重新组织搜索、操作和内容，不能机械上移。不要恢复边角装饰。
- 全部跨项指示条380ms连续移动，只挂载最终页。内容只作短淡入与小位移，详情整幅画面先淡出80ms再淡入160ms，避免标题重影；截图期间跳过重复入场，不生成旧弹窗独立图层或页面缩放。减少动态效果立即到目标。
- 首页左侧4秒单步轮播，右下方4部实际最新作品。封面直接阅读，返回保持当前作品并刷新页码。焦点、后台、离屏或阅读器打开时暂停轮播/无用轮询。
- 库详情原生悬浮弹窗，封面不加背景垫。详情跳转先准备目标数据，不能先关闭弹窗再截图；阅读器入口同步关闭并隔离旧页面。
- 连续模式恢复位置必须在首次绘制前完成。原图加载/失败/等待页要预留高度，优先用真实页面尺寸，缺失时暂用首个已知尺寸；不能让零高度占位导致遍历全书并改写保存页。远端尺寸字段须完整透传，加载后的图片保持自然大小；恢复/跳页期间不能用占位几何改写进度；目标图片解码后再次校准滚动，用户滚动、触摸、滚动条或键盘操作后解除固定并正常回写。
- 发现常驻作品/更新/订阅三个选项卡；更新项显示未读数，不加右侧更新栏或顶部入口。作品筛选保存不得覆盖更新/订阅链接。近期作品来自真实上游，原文标题折叠规则保留。
- 刮削弹窗初始即带双来源状态，加载/错误保留尺寸；不要恢复晚到控件导致的跳动。
- 迁移必须预览来源、目标、容量和冲突；验证后才切换来源，移动才删除独立导入原文件。保持作品身份与阅读记录。
- 迁移复用文件清单的直角勾选样式，保留原生复选/单选输入的键盘操作与焦点；不要直接显示浏览器默认控件。
- 整页加载占位 `folio-route-loading` 和详情等待条 `folio-detail-pending` 不能共用类名或几何样式。
- 源文件只读、外部目录、离线挂载、版本变化与缓存租约遵循已有服务边界，不能在UI里绕过。
- 旧schema升级幂等，受管路径便携；SMTP/认证秘密不返回、不打印。测试必须在私有副本。
- 正式 feature 不导入 demo；继续使用现有 Motion、原生平台功能与Folio控件，避免重复实现/新依赖。

## 验证入口

`npm run dev` 启动整套本地环境。API测试用 `PYTHONPATH=apps/api .venv/bin/pytest apps/api/tests -q`；构建用 `npm --prefix apps/web run build`。前端需要 `E2E_BASE_URL`、`E2E_STORAGE_STATE` 和实际自有数据，各写入用例另有明确的 `/tmp` 环境约束。

本阶段核心用例：`site-layout-refinement`、`site-audit`、`scene-motion`、`home-gallery`；原功能用 `reader`、`reader-direct`、`reader-bridge`、`file-ownership`、`source-operations`、`discover-fixes`、`shelf-navigation`、`media-experience` 等复验。保留错误/空态、手机/横屏、焦点、滚动和修饰键行为。设计验收要等待图片解码，检查冷加载、切换中间帧、快速打断和操作过程，不能只检查动画结束的画面。缓存全局数量检查单独分组，避免已强制关闭的测试浏览器租约污染结果。

连续进度恢复用 `reader-scroll`：实际61页作品从40页恢复，桌面/手机三种缩放；慢加载期间逐帧采样计数，不允许中间回到1/2页或一次请求全书。另测横向封面实际26页作品第20页及末页，不能让短占位或底部滚动限制把进度写成第21页或第24/25页；同时检查加载中主动滚动不会被固定目标拉回。不要只测作品默认第一页。

部署从当前源码构建，保存旧镜像与一致性SQLite备份；核对静态资源、健康、认证和原有数据/源文件后再报告完成。
