- 单密码认证、会话持久化与密码变更；设置敏感值只返回配置状态。
- 远端最新/热门/筛选/标签/详情、直接阅读、真实导入队列；库筛选、收藏、本地标签、继续阅读与历史。

- 语言/置信度刮削、字段差异、本地标签范围、人工治理核对；可选ComicInfo回写和不改源的导出下载。
- 作者/社团订阅、历史基线与增量更新、持久邮件发件箱和SMTP配置；逐页一致性核验后的双来源交接。
