## 动画覆盖与性能

以下**16组正式控件**复用共享 `SlidingIndicator`，同结构demo也复用：

| 区域 | 控件 |
| --- | --- |
| 全局 | 顶部导航、手机导航 |
| 设置 | 设置分区、翻译服务、默认阅读模式 |
| 队列 / 文件 / 导出 | 任务状态、文件分类、导出状态 |
| 我的库 | 网格/列表、内容标签/作品信息 |
| 发现 | 内容标签/作品信息、包含/排除 |
| 整理 | 问题筛选 |
| 统计 | 周期、时长/会话排行 |
| 阅读器 | 单页/连续 |

`transitionTabs()` 一次提交最终目标。450ms原生transform指示条划过中间位置，页面只做一次方向过渡，不挂载或请求中间页面。控制组局部坐标避免页面缩短引入位移；快速点击从当前视觉位置接续，减少动态效果直接定位。回归覆盖中间帧、最终位置、快速点击、焦点和裁切。阅读器进入取消旧切页回调，快速退出重入不丢阅读器；默认模式响应不覆盖用户刚选的模式。

首页SVG动效有限次播放；现有各页SVG场景保留离屏暂停。阅读器背后归档页无限装饰CSS动画运行数量5→0，退出后恢复。手机热门取消持续扇形动效，使用原生横滚。小型导出/历史/词典/排行封面沿用240px缓存缩略图；前一轮同机两张冷加载封面833,696→53,975字节（约93.5%下降）的优化保持。

最终冻结生产构建，本机Chromium、1440×1000、首页直达设置，约2.4秒采样：[原始记录](/tmp/nh-ui-redesign/audit/perf-oct08-final-refined.json)。
